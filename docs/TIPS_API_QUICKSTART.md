## 🚀 Next Steps

### 1. Generate Model Files

**PENTING: Jalankan ini dulu sebelum run app!**

```bash
# Di terminal, jalankan:
flutter pub run build_runner build --delete-conflicting-outputs
```

Ini akan generate file `tip_model.g.dart` yang diperlukan oleh `json_serializable`.

### 2. Update Base URL (Opsional)

Edit file: `lib/core/network/api_config.dart`

```dart
// Pilih baseUrl sesuai environment:

// EMULATOR ✅ (Default - sudah aktif)
static const String baseUrl = 'http://10.0.2.2:8000/api/v1/motorcycle';

// PHYSICAL DEVICE (ganti dengan IP komputer Anda)
// static const String baseUrl = 'http://192.168.1.100:8000/api/v1/motorcycle';

// NGROK (recommended)
// static const String baseUrl = 'https://your-url.ngrok-free.dev/api/v1/motorcycle';
```

### 3. Verifikasi API Integration

Integrasi list tips ke endpoint backend sudah tersedia di:

- `lib/features/tips_perawatan/tips_perawatan.dart`
- `lib/core/services/tips_service.dart`

Yang sudah terpasang:

1. Load data tips dari endpoint `GET /public/tips`
2. Search keyword menggunakan query parameter `search`
3. Search hashtag dari input `#tag` menggunakan query parameter `hashtags`
4. Filter merek dan tingkat kesulitan menggunakan query parameter `brand` dan `difficulty`

Langkah tes cepat:

1. Buka halaman Tips Perawatan di aplikasi.
2. Ketik keyword biasa, contoh: `ganti oli`.
3. Ketik hashtag, contoh: `#oli mesin`.
4. Kombinasi keyword + hashtag, contoh: `servis #daily rider`.
5. Ubah filter merek dan tingkat kesulitan dari panel filter.

### 4. Run App

```bash
flutter run
```

## 🐛 Troubleshooting

### Error: "No part of `tip_model.g.dart`"

**Solution:**

```bash
flutter pub run build_runner build --delete-conflicting-outputs
```

### Error: "Failed to load tips: SocketException"

**Solution:**

- Check backend server running di `http://localhost:8000`
- Check base URL di `api_config.dart`
- Untuk emulator gunakan `10.0.2.2`
- Untuk physical device gunakan IP komputer

### Error: "Unauthorized 401"

**Solution:**

- Endpoint public tidak perlu auth
- Endpoint protected butuh login dulu
- Check token di auth_storage

### Device ID tidak ter-generate

**Solution:**

- Check permission di AndroidManifest.xml / Info.plist
- Service otomatis fallback ke generated ID
